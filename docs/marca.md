# Decisión sobre el título y la marca

## Decisión

Para la demo y el desarrollo se usa el título:

> **Cementazo: Una sátira**

El título evoca el imaginario de un caso real de corrupción, pero se usa como
marco de parodia. El contenido visible no debe afirmar hechos sobre personas
reales, ni usar nombres, caras, logos o símbolos de personas, empresas o
instituciones identificables.

## Búsqueda de marca

- **Búsqueda formal en el Registro de Propiedad Industrial:** pendiente.
- **Búsqueda preliminar en web:** no se localizó un registro evidente con el
  nombre “Cementazo” para videojuegos; **esto no sustituye la búsqueda oficial**.
- **Fecha de esta nota:** 2026-11-21.

## Regla de release

- **Demo gratuita:** puede mantenerse el título con el descargo visible y sin
  monetización.
- **Release comercial (venta, monetización o tienda):** bloqueado hasta:
  1. completar una búsqueda formal en el Registro de Propiedad Industrial;
  2. revisar el resultado con un abogado costarricense;
  3. confirmar que el título y el arte no afectan derechos de terceros.

## Próximos pasos

1. Buscar “Cementazo” y variantes en las clases de productos/servicios
   relevantes (videojuegos, entretenimiento, software).
2. Guardar captura, fecha y número de expediente si aparece algo.
3. Si hay conflicto, elegir un título ficticio antes de abrir la tienda.
4. Actualizar `README.md`, `LEGAL.md` y `GuiJuego.setTitle(...)` si se renombra.
